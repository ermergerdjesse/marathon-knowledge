# How to create custom shipping labels
## SiteFlow > Shipping > Shipping Labels

1. DHL or VIP Order are both custom labels that act differently

### DHL Labels
This prints an extra label before or after the actual shipping label to show production where to place the shipment for pickup by Carriers

### VIP Order
This prints a single label that is a fake shipping method that doesn't go anywhere (customer / pickup)
<br />
This tells production after scanning it at shipping, it prints out, and to place it on the question table along with the label on top or in the book in english and spanish
