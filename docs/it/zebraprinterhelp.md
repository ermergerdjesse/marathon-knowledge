# Zebra ZD420/ZD421 - Configuring/Adjusting Print Width
## Documentation Overview:
### Guide for configuring Zebra ZD421 printer label width on the physical device
#### Procedure
1. Press and Hold the “Pause” button until the indicator lights blink yellow/orange
2. Press the “Feed” button once (the “Pause” indicator light should start blinking)
3. Press the “Pause” button to start the adjustment
 - A series of printer borders will start to print out, increasing in size
4. When the proper border size displays on the label, press the “Feed” button once to set the print width configuration.
